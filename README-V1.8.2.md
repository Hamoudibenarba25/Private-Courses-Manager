# Private Teaching Manager v1.8.2

This release adds early full-cycle payment support for private courses. For a 2,000 DZD four-session cycle, a student who has attended three sessions may pay 1,500 DZD for accrued sessions or 2,000 DZD to cover the entire cycle, including the remaining session. The payment form shows both the full cycle fee and the amount earned so far.

Before updating, export a JSON backup from the current app. Replace the files in the existing GitHub Pages repository with the contents of this ZIP and wait for deployment.

Validation performed: inline JavaScript syntax, package metadata JSON, manifest JSON, and ZIP integrity. Full browser end-to-end testing has not been performed.
