Private Teaching Manager v1.9.11 — Save Handler Update

This package is based on v1.9.10 and includes a save-button handler adjustment for the session form, refreshed app/service-worker version identifiers, and improved handler attachment diagnostics for Save Session and Save & generate receipt.

Preserves the existing localStorage database key: ptm_v1_data.

Before replacing the files on GitHub Pages:
1. Open your current app and export a JSON backup from Settings.
2. Replace the repository contents with the contents of this ZIP.
3. Commit/push the changes.
4. On the device, close the app, reopen it, and refresh/reload to receive the new service worker.
5. Confirm version 1.9.11 and test with a sample session/payment before relying on it.

Important: this is a source ZIP for GitHub Pages/PWA deployment. Always retain your backup.
