# Private Teaching Manager v1.9.5

## Payment workflow update
- Separate Tuition, Insurance and Book payment actions.
- Dedicated Book and Insurance payment forms include group, student, subject, date, amount and method.
- Book payments are restricted to CEFR groups and allocated 100% to the teacher.
- Insurance is available to Private and CEFR groups and allocated 100% to the school/partner.
- Book and insurance obligations remain separate from tuition balances.
- CEFR student rows include a Book Payment quick action.
- Payment history includes category, group, student-name and date filters.
- Cycle reports separate tuition, book and insurance receipts and show teacher/school allocations.

## Update safely
1. Export a JSON backup from your current app first.
2. Replace the project files in your GitHub repository with the contents of this ZIP.
3. Commit/publish, then refresh the installed PWA.
4. Keep the existing browser storage; the local database key is unchanged (`ptm_v1_data`).
