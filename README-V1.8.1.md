# Private Teaching Manager v1.8.1

This release builds on v1.8.0 and corrects attendance-based private-course fees, previous-cycle debt allocation, and student-profile session deletion handling.

## Upgrade
1. Export a JSON backup from the current app.
2. Extract this ZIP.
3. Upload the extracted project contents to the existing GitHub repository, replacing the previous project files.
4. Commit the changes and wait for GitHub Pages to deploy.
5. Open the same app URL and refresh. If the old interface remains, close the app and reopen it after the service worker update.

The local database key is preserved for continuity. Keep the exported JSON backup in a safe place.
