# Private Teaching Manager v1.9.3

This release limits book and annual insurance charges to CEFR courses only. CEFR course fees are allocated 70% to the teacher and 30% to the school/partner; books are 100% teacher income; annual insurance is 100% school/partner income.

Before updating your GitHub Pages files, export a JSON backup from Settings & backups. Replace the repository files with the contents of this ZIP and commit. Reopen the same PWA URL and refresh after deployment.

Data remains local to each browser/device; this update does not sync devices.
