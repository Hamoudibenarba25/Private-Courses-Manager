# Version 1.8.4 — Correct cycle-balance classification

- A payment for a cycle whose teacher settlement is still open is recorded as an ordinary private/revision cycle receipt, attributed to that original cycle.
- Such receipts appear under current-cycle receipts and are included in the original cycle's normal revenue-share calculations; they are not labelled as debt recovery.
- Only payments for cycles already settled with the teacher are recorded as previous-cycle debt recovery and allocated to the current financial cycle.
- The Student Debts list distinguishes an unsettled cycle balance from a true previous-cycle debt.
