# Private Teaching Manager v1.8.7

This release improves Arabic localization. It translates the Student Debts page, Teacher Payments page, dashboard descriptions, financial reports, cycle statements, payment tables and common action/status labels. It also applies translations to dynamically rendered text after each page render and to the printable cycle statement.

Before updating, export a JSON backup. Extract this ZIP and replace the files in your existing GitHub repository. Wait for deployment, then refresh the PWA. The local database key `ptm_v1_data` is preserved.

Validation performed: JavaScript syntax, package/manifest JSON parsing and ZIP integrity. Full browser testing and native Arabic copy review have not been performed.
