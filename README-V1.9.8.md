# Private Teaching Manager v1.9.8 — Private Course Credit Carry-Forward

- Added automatic carry-forward of unused prepaid tuition in Private Courses only.
- Prior-cycle overpayment becomes student credit and is applied to attended sessions in later cycles.
- Cycle and group status calculations include carried credit when determining outstanding balances.
- Payment entry limits account for existing carried credit, preventing double payment.
- Revision courses, CEFR, book/insurance accounting, private-course 75/25 split, and existing local data key remain unchanged.

Before updating, export a JSON backup.
